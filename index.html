3. 글자 스타일

새 환영 화면은 긴 문구를 자동으로 맞춰. 크기를 직접 조절하면 해당 항목은 지정한 크기로 표시돼.

직접 바꾸면 전체 항목이 수동으로 전환돼. 부분 색상은 계속 우선해.

5. 자동재생 묶음

여러 화면을 순서대로 넣고 싶을 때 사용해. 목록이 비어 있으면 내보낼 때 현재 화면 1장만 생성해.

6. 출력 · MagicInfoSlide

이 ZIP은 번호가 붙은 PNG 묶음이며 MagicINFO 서버에 바로 import되는 manifest·재생목록·스케줄 완성 패키지가 아니야. PNG를 MagicINFO 미디어에 등록한 뒤 재생목록과 스케줄을 별도로 구성해야 해.
